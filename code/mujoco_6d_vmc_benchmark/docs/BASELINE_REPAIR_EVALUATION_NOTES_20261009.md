## 当前Task与Strict到底要求什么

当前任务是`planned_hand_corner`放置，不能拿更早要求每个障碍都有充分接触的legacy gate代替。
代码在`source_v9/scripts/validate_office_apparatus_v5_20260917.py`：

- **Task**：完整55秒、没有物理中止，物块曾抬起超过0.10m；结束前持续至少0.5s满足目标支撑、
  XY误差<25mm、Z误差<15mm、物块线速度<15mm/s、角速度<0.15rad/s，并已释放。
  释放要求两指位置和>75mm且物块不再与机器人接触。保持状态按25Hz任务记录累计（每次40ms），
  不是逐物理子步连续支撑的独立证明。仅机械臂到release/retreat不算完成。
- **Strict**：Task通过，且整个实际物理过程没有中止、外部穿透最大值≤0.2mm，并通过
  未知桌角通道的≤0.2mm检查。较大的2mm穿透触发早停；没有早停不等于Strict通过。
- 接触覆盖、反弹、让位/蹭开是诊断，不是当前放置Task的额外成功条件。它们仍须报告，
  不能让完全没碰到障碍的方法靠低力被称作柔顺更好。
- RMSE、峰值力矩、末端峰值速度不是当前Strict中额外设定的三个标量阈值。
  原执行器幅值/变化率、关节命令速度/加速度限制仍执行并审计；命令速度限制不等于
  在外力作用下保证实际测量速度永不超过同一数值。原生阻抗的等效命令/力矩通道另验。

## 相同测试意味着什么

全部16方法共享同一模型二进制、目标、名义规划、物理步长5e-5、55秒上限、扰动条件和gate。
最终16模型在解封前一次锁定；RL两个seed都接受相同8个开发条件，再按已登记排序选一个。
最终每族只有一个冻结模型，24条件不是24个训练seed，也不能把两个seed选优后称为seed均值。

六个神经参考并非全部来自同一teacher数据：ESN和两个RNN为20train/5validation版本，
两个MLP和memoryless为18train/6validation版本。ESN与matched RNN的数据版本相同，
但读出拟合、梯度训练、搜索次数和参数量仍不同；宽度128并不表示参数量相等。
纯RL没有teacher/BC标签；经典搜索、示范生成、模型训练、废弃/重建优化需分账。
因此本批是同测试条件下的系统比较，不是自动满足同数据/同算力的结构因果消融。

不生成或查看封存最终取值。

分析工具中的Wilson区间和“exact McNemar”对应二项/独立配对参考模型；其精确性是对该

## 柔顺指标如何避免误读

- 完整55秒与提前失败的全局指标分开。所有失败仍留在成功率/24分母；缺失基础设施结果
  则是未完成，不能补成物理零分。全局峰矩/峰速列是每回合峰值的均值，最坏穿透单列。
- RMSE相对于实际当时的名义参考；同一规划器可能因各策略的进度不同而处在不同阶段。
  低RMSE不能代替物块推进，停滞也可能使该值很低。
- 接触P95只对实际接触样本计算；冲量是接触力模长的时间积分，不是净矢量冲量。
  无接触为NA；接触覆盖、时长、物块放置与安全必须一起解释。
- 固定事件窗口之外还可能再次碰到人体等静止几何，因此另报完整55秒外部机器人接触。
  该通道不含物块，桌角通道可含机器人或物块；这些通道不互斥，不能直接相加。
- 既定恢复指标要求误差≤25mm、实际速度≤25mm/s、连续0.5s并有后续路径/阶段进展。
  它衡量“稳定回归”，快速通过不一定满足；已恢复回合的条件均值不代表全体恢复时间。
  未恢复及没有足够观察时间均保留删失信息，不填零。
- 双方Strict且接触的配对受力指标是结果条件化子集；适合描述同条件成功后的受力差异，
  不能隐去总表失败或直接解释成网络结构的因果效果。
- 第一次短碰撞可能快于25Hz actor响应；更低首次峰力本身不证明控制器在碰撞发生后已
  实时作出反应。储备池记忆、预先姿态和名义轨迹也可能影响结果。

控制器重放与数值限制验证不是全机器人动力学的独立实现、无源性证明或硬件安全认证。
若RL当前预算内没有学会任务，必须报告有限预算失败，不能以零成功证明RL方法本身上限，
也不能为了ESN排名而隐去实现修复后仍需优化的问题。
