## ESN的柔顺性：哪些改善，哪些没有

全24条件下，ESN相比matched RNN的RMSE低1.229mm、平均峰速低0.01515m/s、
平均峰矩低1.270Nm。但峰矩差的探索性95%区间为[-2.781, 0.030]Nm，不能称为稳健下降；
双方Strict的10条件中峰矩反而高0.119Nm。Task少3条，Strict少1条，不能以低速度替代任务效率。
Task/Strict配对检验分别经15对照Holm校正为0.75/1.0，没有ESN成功率优于该RNN的证据。
