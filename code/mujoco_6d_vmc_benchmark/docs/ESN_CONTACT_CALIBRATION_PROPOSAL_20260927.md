# 待用户决定：独立接触模型标定的研究边界

状态：仅提案，未获用户决定；没有修改材料、solver、世界或安全门，也没有
新增部署传感器。当前proposed参考仍为R34。完整目标保持不变，尚未完成。

## 为什么提出这项选择

保持原物理基准时，当前力驱动ESN在球撞55ms发生前只有零wrench输入，
不可能通过零平衡读出训练改变该首撞。更快本体反馈、只读数值收敛检查、
固定任务位姿下的准备构型筛查和本轮不可部署的接触后理想力矩诊断均未
减小首峰。本轮克隆状态审计进一步核实，约104/191um深度处，约62.4m/s²
的自由法向加速度变化，经耦合接触约束求解仅剩约.000442m/s²，主要表现为
接触力改变。它解释局部现象，既不是所有纯本体控制器不可行的定理，也不是
接触参数错误的证明。不能为了ESN过线直接把接触调硬。

证据：`outputs/esn_office_contact_response_20260927/CONTACT_RESPONSE_AUDIT.json`；
原轨迹、球细节及全部物理子步与parity逐值一致，独立状态重建求解通过。

## 若用户允许扩展到独立标定

1. 先确定代表的实际球体/接触材料与几何，并取得独立标定依据：球质量、
   碰撞前后法向速度（恢复系数）、接触持续时间，以及可获得时的力时程或
   压缩量。当前没有这些物理实测资料，不能编造“真实标定值”。
2. 用独立单次碰撞校准工况拟合接触响应，保留预先划分的验证工况；不读取
   ESN任务成功率或.2mm是否过线来选择参数。不得把材料调硬当作模型优化。
3. 冻结一份有版本号的共同物理协议；全部控制器使用相同接触参数、几何、
   初态、外部驱动和指标。任务/外部穿透≤.2mm要求仍保留。
4. 原基准全部失败和源/hash完整保留。新物理版本单列结果，不能写成R34或
   R36在原冻结基准上已经通过；是否接受新版本作为论文主基准须明确记录。
5. 新协议先跑开发场景的zero/VMC/R34配对，再按同一验收条件决定是否开启
   保留场景。标定收益与ESN控制收益分开归因；不能制造ESN独有优势。

## 若用户要求保持原物理模型

继续遵守该选择；不偷偷标定或放宽门槛。现有证据只排除了当前零输入读出
变化及已试机制，未排除所有纯软件方案。任何新的软件实验必须说明如何在
不使用外部状态/事件时钟、不改变初始条件/任务门的前提下改变首撞因果链，
然后预声明有限预算。现阶段没有经过验证的这种方案，不重复启动既有失败
的gain、scale、带宽或读出扫描，也不提前解封保留条件。

这是研究范围选择，不是额外感知授权；用户先前禁止预碰撞感知的决定不变。
