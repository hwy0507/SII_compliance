## 需要明确的研究边界：独立预碰撞安全层提案

原交接文档 §0、§1.1–1.2 要求 student 只用本体信息，应对无法提前预测的
接触；§7.3 禁止 ESN 获得其他方法没有的视觉或未来信息。不能为了把这个
首次冲击数字压过线，给 ESN 暗中注入球状态或事件时刻。

一个尚未执行、需用户决定的新分支是：保留现有 proprio48 ESN 作为接触后
柔顺/恢复层，新增独立的、对所有方法共享的真实可部署预碰撞感知安全层。
具体待评估接口为：

1. 输入只能来自带时间戳的 RGB-D/距离传感序列、相机标定和机器人编码器；
   不用 MuJoCo body/contact 真值、未来轨迹或脚本事件表。
2. 从连续观测估计相对运动和不确定性，向共享名义任务/WBC 提供有限幅值的
   短时安全动作；不把预测事件标签直接注入 ESN 储备池。
3. 保留同一个 ESN checkpoint、同一个安全门槛和全部原始球撞条件；所有
   baseline 得到相同感知与安全层。必须分别报告感知层作用与 ESN 作用。
4. 独立验证漏检、误检、观测延迟和遮挡；无法满足延迟预算时不能宣称安全。

这会扩展论文系统边界，不能伪装为原来的纯本体感知方法自行解决了首次冲击。
已向用户询问是否允许该分支，当前没有实施新感知或改变 student 输入。
原研究边界内的压力测试和数据归档继续进行。
