## 为何目前不能继续到完整验收

当前架构在首撞之前的wrench、零初态储备池和动作都为0；单改保持零负载
平衡的读出不可能改变这段固定初态/名义控制前缀。已执行的估计校准、读出
聚合/平衡正则、快速反馈、数值收敛检查和固定末端位姿的准备构型筛查均
没有解决该门。不可部署的理想力矩诊断和独立状态求解提供了局部控制
影响被耦合接触约束抑制的证据，不能据此宣称所有纯软件控制均不可行。

目前没有一个新的、具体且有证据支撑的纯软件方案可直接继续实施；重复
既有gain/scale/带宽/读出扫描没有新的因果假设。现有安全/曝光失败不能
通过删回合、提前打开保留集、降低球速或放宽.2mm门来绕过。

已准备的下一条具体路线是`ESN_CONTACT_CALIBRATION_PROPOSAL_20260927.md`：
用独立物理依据标定所有方法共用的接触模型，再版本化冻结并配对重验。
这改变当前冻结物理基准，需要用户决定；当前亦缺少实际材料/接触标定
数据，不能从ESN是否过线反向选取参数。它尚未实施，也不保证一定解决
全部安全及推杆曝光问题。
