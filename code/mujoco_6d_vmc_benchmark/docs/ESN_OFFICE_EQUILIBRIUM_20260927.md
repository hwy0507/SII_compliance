## 已完成的离线候选

在恒定本体估计wrench下，将冻结128维储备池运行800步至固定点。固定网格
包含正负六轴负载，利用VMC方程的解析平衡位置构造目标，并与教师实际积分
结果核对。原ESN部分小负载的恒定输出符号与负载相反，说明其平衡响应存在
蒸馏误差；这些偏差尚未被证明是某一闭环失败的原因。

预声明方案只进行一次闭式线性校正。保持win/w/leak、非线性读出及全局
输出增益.5不变，只修改各轴线性读出；目标同时约束原训练历史上的输出
变化和静态平衡误差。无岭参数/权重搜索、无重选checkpoint、无在线VMC调用。
原R33训练历史和合成验证切分保持不变。固定点间插值检查属于开发诊断，
不是机器人盲测。
