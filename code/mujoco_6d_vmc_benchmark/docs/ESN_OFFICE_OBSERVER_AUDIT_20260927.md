## 下一步：一次固定速度尺度校准试验

原`motion=tanh(dq/.005)`与静摩擦不确定区间会在低速时抑制部分真实接触。
这是保守估计设计，不直接判为程序错误。在理想的正向匀速、库仑摩擦幅值f
和同向外力F情况下，估计未滤波值为max(F−2f(1−tanh(v/scale)),0)。
例如v=.001rad/s、f=.4Nm、F=.5Nm，原尺度抑制成0；scale=.001保留约.309Nm。
无接触的正确摩擦平衡仍输出0，已有对应物理平衡单元测试。

固定尝试scale=.001rad/s，其他负载滤波、模型和控制限幅不变，原默认值
.005保留。R34 checkpoint不重训，在original/hard各运行ESN及zero，共四条
55秒。两种方法和任务规划器都接收同一校准后的本体估计；任务阈值仍不变，
实际支撑/松爪/放置继续独立物理验收。不得将输入变化隐瞒为纯读出改进。

不是另一个闭环控制器。结果不是统一改善：ESN两条误差增加约44%/46%，
zero两条下降约11%。不能据zero的估计误差改善宣传校准成功。

两个ESN失败均停在load_transfer。全卸载阶段616/586个策略观测中，位置

约89%的样本满足要求，旋转条件全部满足。因此直接阻止任务推进的是位置
条件，而非完全没有检测到卸载。候选改变估计和动作、轨迹后会形成反馈耦合；
上述证据不能进一步单独归因到某个ESN神经元，也不是放宽位置门槛的理由。
