# VMC teacher 与 ESN 联合优化：当前研究目标

用户已明确授权优化 teacher 和 ESN 两方面。本记录取代此前“软件路线已无
具体下一步、需先决定物理标定”的推进判断；历史实验、失败和诊断仍保留。
当前目标未完成，但不再把接触物理标定作为开展软件优化的前置条件。

目标：在 office-v5 人手推压、球撞、推杆及静态障碍下，联合优化纯本体
VMC teacher 与储备池 ESN，使物理抓取、搬运、放置、松爪及撤离满足原始
安全、接触曝光和跨条件稳健性要求。不得假设所有 baseline 失败或 ESN
必然独占优势。当前六个开发回合 task 6/6、strict 3/6，不代表硬件验证。

保持原物理、外部穿透 ≤0.2 mm、执行器幅值/变化率限制、原任务成功条件
和接触曝光要求。禁止视觉、距离、球状态、事件时间、接触真值和阶段标签
进入 actor；不重启自动任务、不发布、不提交。三个保留布局继续封存。

## J1：先测 teacher 能力，固定八回合预算

使用 R36 已存档的 R34 同源评估快照，新增独立 wrapper，不编辑旧评估器。
四个固定参数配置 × 原始/强球撞两个已暴露开发条件，均完整 55 s，种子、
物理步长、WBC、观察器、任务和世界完全配对。最多两个新 worker；启动前
查全机仿真进程，保留另一项正在运行的 Simba 训练，总并发不得超过四。

| 配置 | 相对默认 teacher 的变化 | 机制假设 |
|---|---|---|
| default | 无 | 补齐精细物理下 teacher 参照 |
| half | 七维动作统一乘 0.5 | 分离输出强度与 ESN 模仿误差 |
| damped | half 基础上阻尼乘 2 | 减轻虚拟动态过渡与恢复振荡 |
| stiff | half 基础上刚度乘 2、阻尼乘 sqrt(2) | 保持阻尼比、减小持续负载偏移 |

这是有限的 teacher 机制筛查，不是穷尽搜索，不预期同类零输入架构修复
首次球撞。先做包装器默认参数的短轨迹精确一致性检查，再启动全量队列。
参数在结果产生前冻结；不能按穿透结果重选物理或减弱外部扰动。

记录每一步估计 wrench、teacher 过滤状态/位移/速度、原始及应用 action，
以及原有观察、物理子步、MJB/XML、任务成败、接触覆盖、seed、源/参数 hash。
应用 action 指提交给共同执行接口的动作，不能把它等同实际执行力矩；
实际执行结果由物理子步 generalized actuator torque 和机器人状态核验。

所有八回合必须报告，包括执行异常。先按完整任务、安全及接触覆盖判断，
再报告 waypoint 位置误差、实际峰矩、末端峰速和最终放置误差的权衡；当前
waypoint RMSE 不能标成连续轨迹跟踪误差。不得用主观综合分掩盖安全失败。
J1 不单凭两条件宣布获胜或替换 R34；有改进的候选再做全部六开发条件。

## 后续实验分支

1. 若 teacher 出现闭环改善，使用其实际执行历史进行蒸馏，分别测 teacher
   能力、ESN 模仿误差和学生闭环差距，而非仅拟合解析合成标签。
2. 若所有固定参数候选仍受限，转向本体状态驱动的 teacher 动态与恢复
   机制，并在配对条件验证；不把 J1 阴性结果写成 teacher 已优化到极限。
3. ESN 结构探索考虑关节位置/速度、估计负载及多时间尺度记忆。逐字段审计
   输入来源；增加输入并不自动证明有效，需匹配预算的闭环记忆消融。
4. 开发门槛全通过后，冻结模型再执行原保留条件，失败照实保留。
