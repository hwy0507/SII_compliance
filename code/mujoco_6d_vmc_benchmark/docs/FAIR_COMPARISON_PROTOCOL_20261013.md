## 哪些旧结论不能直接使用

- 旧 ordinary 与 matched 的特征、时间尺度、初始化、损失、参数数目和验证机会不同。
- 最新 matched RNN 三seed三学习率都选回 update0，闭环等于父ESN；不能把它当成
  “RNN有效训练之后仍然不如ESN”的证据。保留update0是合理选择规则，强行禁止它也不公平。
- 旧闭环仅一个预指定训练seed、8个反复开发的条件，不能声称独立泛化；旧数据量对比还混入teacher变化。
- 经典/RL的训练来源、预算和部署后端不同，完整性审计不等于充分收敛或全部实现性质已证明。
  阻抗是本体状态反馈的原生力矩控制，不把它伪装成与神经网络相同的内部WBC。

旧208回合和全部失败保留，新结果不会覆盖历史表。

输入/循环矩阵、初始读出及训练片段顺序。禁止直接上下文产生动作，保持零负载静止平衡。

每1000更新验证并含update0。损失统一为原始未clip请求动作的加权MSE和相同读出L2项：
`[sum(w*error²)+0.1*sum(normalized_readout²)]/(7*sum_train(w))`。
部署clip/public filter不变，不再只给神经网络加delta loss，也不在训练时用输出clip杀死饱和区梯度。
这纠正目标不一致；不据此宣称已经证明旧RNN退回update0的唯一原因。

固定rho=.8、input gain=.25，不根据这批验证/闭环重新搜储备池。
每个run按验证动作MSE选checkpoint，每family按三个seed的平均验证MSE选学习率。
seed=`2026101301/02/03`，全部进入闭环，所有39拟合先完成并写MODEL_LOCK，再开始新仿真。
记录每个参数梯度、实际更新量、完整选择历史、训练曝光、模型大小、耗时、torch→numpy重放、
非本体字段隔离和零负载检验；RNN如果仍选择update0，必须公开而不是改名包装。

同宽度不等于同可训练参数或同FLOPs；这两项是机制差别，分别报告，不能同时声称严格配平。
解析ESN与微调RNN是辅助机制/训练方案比较，不能混入主对照的相同优化预算结论。

## 报告规则和资源

主要结果是原Task与Strict；同时完整报告RMSE、峰矩、峰速、各事件接触覆盖/P95/冲量、
恢复时间删失、早停。没有接触的P95为NA，失败全部进分母；早停/卡住导致低力不作为胜利。
主对照ESN-gradient相对RNN/MLP的差值采用训练seed与条件两轴配对bootstrap（2000次，
seed713）给描述性95%区间，不挑最好seed，不挑只对ESN有利的指标，不声称多重比较显著性。
3seed、8条件精度有限；表内RL/经典训练信息和预算差异单列，不能把所有系统差距归因于ESN。
