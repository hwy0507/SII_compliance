## 失败机制的证据

下表来自第二版只读诊断的 166 个已审计回合，截取每回合最后观测到的 5 秒；
“末段误差/速度”是回合尾段中位数再跨回合取均值，最后一列是控制步动作变化率限制触发率。
样本量不齐，这是诊断数据，不是新的最终成功率排名。所有下列 baseline 回合均完整执行55秒。

|方法|已诊断回合|最终阶段|末段位置误差 mm|末段速度 mm/s|变化率限制触发比例|
|---|---:|---|---:|---:|---:|
|经典 VMC|11|carry|15.52|0.43|0.1%|
|经典导纳|9|carry|16.40|9.52|66.7%|
|经典阻抗|10|lift|27.83|0.42|0.0%|
|RL 调 VMC|10|carry|15.07|0.32|0.7%|
|RL 调导纳|10|carry|14.69|10.09|67.7%|
|RL 调阻抗|11|carry|16.26|1.15|0.0%|
|RL 直接动作 metric|12|approach|74.42|37.16|95.4%|
|RL 直接动作 task|10|lift|190.84|8.89|93.4%|

1. **VMC/调参 VMC：受阻后形成近静止平衡，未实现脱困。** 第一个预注册条件 `000`
   的末段位置误差分别 15.14/15.96mm，速度仅 0.254/0.234mm/s；物块距放置目标仍约
   113/112mm。原始物理子步显示末5秒仍有未知桌角接触，edge robot-or-payload 力幅值和
   均值约 6.00/5.13N。原路点直接到位要求12mm，另有切平面重入条件；这两种控制器停在
   carry 的第18路点，没有推进到放置。不能仅因 tracking RMSE/峰矩低就解释为柔顺成功。
2. **导纳：末段仍在动，但没有稳定到位。** 其速度和变化率限制触发明显高于 VMC。
   这支持检查虚拟参考偏移、恢复阻尼和公共动作滤波的相互作用；尚无因果消融证明具体参数
   是唯一根因，不直接从该测试集调参数。
3. **经典阻抗：无外部接触时仍有带载抬升静差。** 条件000末段误差27.96mm，速度
   0.421mm/s，外部/球/人/棍/未知边/柱接触记录均为0；“外部接触为0”不排除手持物负载。
   需在独立开发条件核查移动平衡点、负载补偿和伺服接口，不能归咎为所有障碍都太难。
4. **直接动作 RL：输出与执行限制经常冲突，尚未学会可靠到位。** 两种策略约95.4%/93.4%
   的控制步触发公共变化率限制，误差大且停在 approach/lift。条件000 metric 的末段旋转误差
   约0.998rad，WBC scale 中位数0.304；task 版本有明显大幅残差和未消除的接触。
   这是策略行为证据，不是GPU没启动或checkpoint加载失败。奖励/训练曝光/动作尺度哪个因素
   主导，仍需独立开发条件上的匹配预算消融，不能从这些评测回合反向选最优策略。

经典 VMC 的当前实现只将估计 wrench6 输入柔顺律，RL 调 VMC 可改变其参数但没有改变该
控制结构；纯 ESN/RNN/MLP 则可从允许的本体/参考相对输入学习恢复动作。这是实现设计上的
差别，不能据本轮零成功断言经典控制或RL方法本身不可能完成任务。现阶段未证实新的接口
bug，不热改当前冻结模型、动作映射或任何成功门槛。
