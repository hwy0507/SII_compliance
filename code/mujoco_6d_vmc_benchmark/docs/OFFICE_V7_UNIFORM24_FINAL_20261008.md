## 统一口径

固定 office-v7 布局/MJB、同一组24条分层扰动参数、每方法一个预先锁定模型、正式 dt=5e-5。
这检验固定布局下的扰动参数泛化，不是24种几何布局，也不代表所有方法历史训练预算相同。
Task 要求完整时长、抬升超过0.1m、释放后物块在目标XY25mm/Z15mm范围内受支撑、
线速度<15mm/s、角速度<0.15rad/s，并在结尾连续稳定至少0.5s。
Strict 是 Task 加物理有效、外部/未知桌角穿透均≤0.2mm；沿用冻结实现。
所有失败计入24分母。RMSE为每回合全物理时间加权误差后跨回合平均；峰矩/峰速为各回合峰值的均值。
最坏穿透为24回合最大值。低误差、低力矩的停滞失败不能当作柔顺完成任务。

## 结论和限制

- ESN Task20/24、Strict16/24，在本轮学习策略中最高。相对matched RNN（17/24、14/24），
  Task多3回合、Strict多2回合；RMSE低4.61%、峰速低2.53%，但峰矩高2.55%。
- ESN人手/棍P95为13.380/16.817N，matched RNN为14.244/17.895N，约低6%；
  棍冲量却为34.255对32.773N·s，不能将P95优势写成所有接触指标领先。
  人手稳定重入8/24对12/24，棍1/24对0/24；恢复时间是仅恢复回合的条件均值，不能忽略未恢复者。
- ESN仍有4次Task失败（carry3、retreat1），另有4次Task通过而Strict失败；最坏穿透0.696mm。
  不满足“全部任务安全通过”，不声称已达到真实陌生环境的安全泛化。
- ESN对matched RNN的配对Task仅ESN成功6、仅RNN成功3；Strict为7对5。
  双侧精确McNemar p分别0.5078125、0.7744140625。24配对条件不足以支持显著成功率优势。
  Wilson95%区间：ESN Task64.15%–93.32%、Strict46.71%–82.03%；RNN Task50.83%–85.09%、Strict38.83%–75.53%。
- Enhanced teacher为参考行：24/24 Task、20/24 Strict；其手工设计/信息使用须另述，不能混作纯本体学习策略。
- 经典VMC/导纳、三种参数RL和nominal zero均停carry；经典阻抗与direct-task RL均停lift，
  direct-metric RL均停approach。它们每行24个真实55秒失败，不是没有运行或checkpoint加载失败。
  性能修复尚未完成；后续应在独立开发条件检查负载补偿、导纳恢复和RL输出与执行限制的相容性。
  不以当前24评测条件反向选择权重，也不能以这些实现的失败证明经典/RL方法普遍不可行。
