# 旧综合场景12秒后抽动：冻结轨迹诊断

2026-10-13。结论：存在真实的ESN修正指令振荡，不是单纯视频问题，也不是名义轨迹正常转向。
较明确的放大环节是读出中的“当前估计负载×位置误差”交叉项；旧任务远终点参考使位置误差
特征长期在截断上限。棍子接触后出现明显逐控制周期交替，脱离外部扰动后仍未完全消退。
本次不改模型、场景、门槛或滤波参数，没有新物理仿真。

- 10.24s切换到carry，之后直到41.92s均是同一阶段，没有12s处阶段切换或姿态目标跳变。
  旧任务直接使用carry阶段终点，不是新版短距离规划路点；10.24–11.48s的y位置误差均值429.7mm，
  11.48–16.68s均值437.7mm。模型用 `clip(error/.08,-4,4)`，该y通道两个窗口100%截断到+4。
  截断保证数值有界，但不保证负载交叉项的闭环增益合适。

  因此不能说“棍子是唯一初始原因”，其接触之后振荡明显加重。

## 为什么会放大

原checkpoint使用固定reservoir、线性读出和clipped-linear输出。线性读出不仅读取记忆状态，
也直接读取当前负载与上下文的乘积。对同一已保存轨迹做精确代数分解：

| x输出裁剪前分量（无量纲） | 13.00s | 13.04s |
|---|---:|---:|
| 当前负载直接项 | +0.0397 | +0.0605 |
| 储备池状态项 | +0.9957 | +0.1039 |
| 当前负载×上下文 | +3.1179 | −1.0751 |
| 储备池×上下文 | +0.0456 | −0.2443 |
| 合计 | +4.1990 | −1.1549 |
| 其中：当前负载×y位置误差（上方交叉项的子项） | +3.9772 | −1.0759 |

合计超过±1后被裁剪，再乘0.32m/s得到±320mm/s。11.48–16.68s，
当前负载×上下文的相邻步变化RMS3.692，储备池状态项0.621；
其中负载×y位置误差子项变化RMS4.341。各分量有抵消关系，不能把这些数字当作独立因果贡献率。
它们足以定位主要输出放大通道，不能仅凭“模型叫ESN”就把全部振荡归咎于储备池记忆。

负载来自速度差分逆动力学残差，经40ms时间常数滤波，再映射到等效末端wrench；
它不是接触真值，包含抓持载荷、估计残差及动态误差。13.00/13.04s估计Fx为+3.655/−0.820N，
与动作交替同时存在。可疑闭环是：负载估计变化→交叉读出放大→运动修正→估计变化。
仅靠已记录闭环数据不能确定观测器误差、接触、读出增益各自的因果份额。
尚未对teacher训练数据做分布覆盖核查，不能将分布外泛化不足写成已严格证明。

## 限制器和已排查因素

- 共同线速度残差变化率1.2m/s²，即40ms最大变化48mm/s；上述+64.089/+16.089恰好相差48mm/s。
  11.48–16.68s中89.1%的相邻x动作达到该变化率边界。过滤器减小幅度，不能消除请求不断翻转。
  不是残差权限不足，也不能用简单放大上限作为本次证据支持的修复。
- 名义x相邻步变化RMS0.906mm/s，ESN请求为513.889mm/s；主振荡已在策略输出端出现。
  名义速度受反馈影响仍会变化；这里不是证明名义控制在整个闭环中没有任何作用。
- selector_pulse全程0帧；同阶段参考不反复切换；不存在该脉冲触发导致的抽动。
- 由保存qpos重建的Jacobian全程秩6，最小/最大奇异值比最低0.053946，未跨rcond0.03阈值。
  不支持“最小二乘秩频繁切换”的解释。重建wrench与记录最大差0.0003632，
  保存qpos与live动力学缓存不能当作完全同一时刻状态；因此不声称该映射逐位重放一致。
- 策略读出按保存观测重放在2e-12绝对容差内一致；动作/储备池/公共过滤器的精确重放
  已由上一轮独立审计通过。实现能复现不等于闭环行为好。
