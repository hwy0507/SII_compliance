`stats.events.rod`统计的是棍—机器人接触，缺失不意味着棍子没碰任何东西。

这些是保存姿态的几何接触，不能当作精确累计接触时长/真实动力学峰力，
也不证明帧间没有其他接触。正式机器人接触覆盖判据仍未通过。
