## 纯 ESN 的实际结构

部署时只有神经网络输出7维公共action，再经过所有相应方法共享的过滤与WBC，不调用VMC teacher。
48维接口中读取18个既有本体/参考相对字段：14:17名义运动、20:23参考位置误差、26:29速度误差、
39:45观察器估计负载、45:48名义方向。估计负载不等于MuJoCo接触真值；actor不读取球/障碍状态、
事件时间、任务阶段、视觉或距离。接触真值只参与离线评价，不送给actor。

主要固定ESN有128个单元，循环矩阵与输入矩阵随机生成后冻结；32单元一组，基础时间尺度为
.04/.12/.5/2秒。由估计六维负载、其绝对值和与12维本体context的乘积构成156维固定输入特征。
状态按有界tanh和leaky更新。输出特征包括当前负载、128状态、二者绝对值及load×context；
12个context-only读出系数强制为零，共2884个可学习线性系数。这里的“线性读出”指对这些明确
披露的固定非线性特征线性，不是只有原始128状态的标准Wout。没有额外可训练隐藏读出层。
七维输出独立学习；a0限[0,1]，其余限[-1,1]。恢复teacher的slowdown在z恢复修正之前产生，
故不能强制学生a0等于修正后残差范数。

对最终固定ESN，令归一化估计负载为`x`、12维参考相对本体context为`c`、128维储备池为`h`。
确切部署计算为：

```text
x = clip(obs[39:45] / [8,8,8,1,1,1], -12, 12)
c = concat(clip([obs[14:17]/.06, obs[26:29]/.06, obs[45:48]], -4, 4),
           clip(obs[20:23]/.08, -4, 4))
u = concat(x, abs(x), outer(concat(x, abs(x)), c).flatten())
h[t] = (1-leak) * h[t-1] + leak * tanh(Win @ u + W @ h[t-1])
phi = concat(x, h[t], abs(x), abs(h[t]), outer(concat(x, abs(x)), c).flatten(), c)
raw = phi @ readout
action = concat(clip(raw[0], 0, 1), clip(raw[1:7], -1, 1))
```

`leak=1-exp(-.04/tau)`；每个时间尺度32单元，`Win/W/leak`冻结。readout最后12行固定为零。
只对其余412×7系数做带样本重要性和训练特征尺度归一化的ridge回归。load×context的144个
固定乘积并非额外可训练神经元，但确实增加特征表达能力，不能在和普通MLP比较时隐去。

有限幅tanh与0到1之间的leak使从零初始化的每个储备池状态始终在[-1,1]；限幅读出使动作有界。
这只是网络内部状态/输出性质，不是机器人闭环稳定性或全局无源证明；仅有循环矩阵谱半径小于1
也不应直接宣称全局echo-state收缩。公共规划、WBC及执行器限制仍是各方法共有的控制栈，
“纯ESN”表示学习柔顺action不调用teacher，并非移除了这些共有底层。

每个seed按rho[.5,.8]×输入增益[.08,.25,.6]×ridge[.001,.1]共12个配置，以整条synthetic
身份留出的requested-action MSE选型。条件漏率、可训练漏率、读出增量/积分损失、无记忆重训和
DAgger均是另列实验；不能将可训练漏率版本混称经典readout-only ESN。

## Teacher、数据与对照

Teacher以原VMC为基础，允许原本体信号触发的有界主动参考相对恢复。成功35mm配置的恢复
参数为threshold .5N、attack .12s、release1s、offset .035m、gain4/s、速度限.12m/s、
progress衰减尺度.02m。它属于增强的model-based baseline，不是纯被动VMC，也无全局无源保证。
原始VMC、固定参数VMC及增强teacher分别报告，不用一个较弱teacher替代所有model-based对照。

35mm基础数据同时保存服务器成功和本机失败teacher的实际请求与实际过滤输出，另含旧学生历史
的明确反事实teacher标签。48条synthetic完整身份分为40训练/8留出，长度1000；一半检验负载
撤去但尚未恢复前进的记忆情形。真实历史权重48、反事实16；所有实际/反事实来源和失败状态均
存lineage/hash。synthetic身份留出不是物理场景泛化证明。DAgger追加全部四条指定开发历史，
不挑成功，原留出数组逐元素不变；最终四个物理条件禁止用于学习。

本轮主35mm训练集不是“3000条独立成功环境”：它有2条实际teacher历史（1成功、1失败）、
2条旧学生历史的反事实标签，以及48条synthetic负载历史。不能用帧数/合成序列数替代真实物理
条件覆盖。旧teacher-bank工作另存；本轮所支持的泛化范围只由冻结后实际测试的四条件决定。

普通MLP与Elman RNN均128隐藏单元、同数据/字段/目标/seed，学习独立a0；训练12000更新，
64步截断反传、batch8，requested MSE+.25动作增量+.25的.64秒积分动作代理。代理不冒充机器人
实际RMSE。两种方法训练活跃参数量不同，ESN也有额外固定特征先验，不能把同宽度称作同容量或同FLOP。
新float64训练用于消除长RNN的Torch/NumPy导出差异，原float32导出失败及额外曝光均保留。

补充对照包括：

  `proprio48_context_network_v1`契约，标为MLP/RNN；它们不是固定储备池ESN。

## 评价次序与不可混淆的结论

原任务成功：真实松爪、物块由目标桌面支撑、没有机器人接触；目标XY<25mm、Z<15mm，线速度
<15mm/s、角速度<.15rad/s，在最后连续至少.5秒有效；还要求完整55秒及曾抬升>.1m。
Strict进一步要求原外部/凸边穿透≤.2mm；执行器幅值/变化率另做独立审计。Strict不是硬件安全
认证，也不代表所有碰撞物均接触或推杆保持期已主动滑脱。
公共filter中的速度限制作用于指令，不保证外力撞击后的实际末端速度有全局硬上界；实际峰速
独立报告，不能把它误写为strict判定已经覆盖的硬件安全认证。

原放置实现每个25Hz观测满足条件即累计.04秒，13个连续有效样本计.52秒（首末时间戳跨度.48秒）。
本轮不改变这一既有离散判定；独立放置审计重建相同13个末态，并准确报告样本数、跨度和累计量。
不能将其称为连续物理子步的.5秒支撑/释放证明；三项运动指标、接触载荷和穿透则有完整物理子步记录。

完成时间精度补充：原汇总字段`final_stable_placement_reached_s`按最后有效保持量插值到.5秒，
比13样本实际触发早.02秒。该原始字段和表格保留，最终独立`COMPLETION_TIMING_AUDIT.json`
依据相同保持计数及真实25Hz时间戳给出`sampled_gate_crossing_s`；绝对完成时间以此为准。
共同成功回合的成对时间差不受这一共同.02秒修正影响。该修正只涉及报表采样语义，不改任何gate、
轨迹、成功标签或模型选型，也不把离散计数升级为连续接触证明。

先报告全部回合task/strict和失败原因，再比较共同成功样本的稳定完成时间、接触p95/冲量/持续时间、
推杆保持期脱离间隙、卸载后继续前进并稳定回到路径的时间。无接触是NA，恢复遇下一障碍按先验
删失，不能填零或最大时长冒充实测。较短接触或较小峰力也可能来自不同接触曝光。
完整任务RMSE、实际驱动力矩峰值、实际末端峰速及机械功/力矩总变差保留为诊断。参考路径进度
会随任务执行变化，低RMSE可能只是卡住；因此不能取代真实放置。没有事后加权的“冠军分”。

接触力采用同一子步同组各接触点三维接触力模长之和，不是净合力；冲量是该非负总量的时间积分，
也不是物体净动量变化。p95仅在总接触力>.05N的实际接触样本中计算；低于阈值的小量仍计入窗口冲量。
凸边统计包括机器人或载荷，其他事件为机器人与指定障碍物；具体列语义随原始数据保存。
接触位移从首次实际接触起计算。力矩总变差和绝对机械功为数值诊断，不能冒充全局无源性证明。
