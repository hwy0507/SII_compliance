## 先验评价层次

1. 主终点为原task与strict、完整时长/安全终止、实际释放稳定放置、完成时间（失败记未达到，
   不记零），全部方法/回合保留分母。不能用低误差或接近目标替代成功。
2. 报告每个扰动的实际接触覆盖、首次/末次时间与冲量；无接触保持在任务分母，接触恢复指标
   记不适用，不计零或“成功避让后的恢复”。同世界不保证同接触曝光，须披露。
3. 柔顺诊断：球的冲量/峰力与碰后偏离、恢复；人手/杆的接触力时间统计、受力位移、保持期内
   连续无接触区间/重接触，以及卸载后重返路径和继续推进。力指标按原生子步计算，未记录的
   通道不能由25Hz轨迹插值冒充。短时碰撞峰值依赖预碰状态/材质，不能声称25Hz策略瞬时响应。
4. 恢复采用原任务容差导出的25mm位置带、25mm/s速度带、连续.5秒；另要求路径游标/任务
   推进，避免“在障碍前静止”获得好恢复分数。事件卸载基点取公开固定时序，恢复若遇下一
   扰动/终局仍未满足则报告右删失与观察时长，不用最大时长伪装实际恢复时间。
5. 保留完整任务RMSE/误差时间积分、实际qfrc_actuator峰矩、实际末端峰速和穿透；补充可复算的
   指令总变差/振荡和执行能量诊断。未通过任务的这些统计仅描述失败，不构建加权“冠军分”。
6. 先比较完整任务和安全，再在共同成功及实际接触样本中比较恢复/接触负担/效率的Pareto关系。
