## 目标与成功定义

用户图片对应`office_v5_corner_top`上层厚桌板，实际表面z=0.520 m，
范围x=[0.570,0.730]、y=[-0.350,0.150] m。选择靠初始人手的一侧桌角，
把目标物块中心设为 **[0.690,-0.310,0.545] m**，距两条桌边各40 mm。
绿色圆盘只在渲染时标记25 mm目标区域，不进入碰撞模型或actor输入。

新协议ID：`office-combined-v4-planned-hand-corner-v1`。
`task_success`要求完整55秒、物块曾抬升>0.1 m，最终连续0.5秒满足：

- 物块由该桌板实际承托，XY距目标中心<25 mm、Z误差<15 mm；
- 手指张开总宽度>75 mm，并且没有机器人—物块的承载接触；
- 物块线速度<15 mm/s、角速度<0.15 rad/s。

不要求必须撞柱子、球或推杆，也不以机器人完成特定撤离距离作为任务成功条件。
`strict_success`在这个**新协议**中表示`task_success AND physical_valid`，
仍检查原0.2 mm外部穿透限制和物理中止；`legacy_strict_success`保留旧的必需接触覆盖判据。
`passed`字段仍是旧器具接触验收，不能当作本新任务的主成功字段。
三项运动指标、接触时间/力、穿透分别报告；未触碰障碍不代表柔顺能力得到验证。
旧协议的默认入口、任务定义和结果不变，禁止把新旧success率混算。

## 规划与接口

实现：`scripts/planned_hand_corner_20261002.py`。
已知静态地图上进行payload包络A*规划（10 mm网格、2 mm扫掠检查、26邻接），
若直连扫掠安全则直接采用；随后生成10 mm参考路点。
这次静态搬运直连可行，A*未扩展节点，非人为强迫绕路或碰撞；障碍绕行单元检查通过。
附加放置姿态搜索0,-5,...,-35度，通过IK检查关节限位、位姿误差及机器人静态碰撞。
固定竖直姿态在目标附近存在约4厘米IK误差；最终选择-35度，同时满足放置点与上方
25 mm接近点。搬运前分5度步长转姿，之后下降、松手、撤离。

规划只访问初始化静态布局，不使用球、人手、棍子状态或事件时间来决定在线参考进度。
动态物体照常作为接触扰动；球2秒、人手3秒、推杆12秒启动不变。
ESN仍接收原48D本体/参考输入，输出7D动作，不添加外部感知、接触真值或VMC混合。
松手由已知目标与实际机器人位姿/速度决定，物块支持真值仅用于独立任务评分。
规划检查是payload扫掠+机器人路点检查，不等同连续全机械臂碰撞证明；后续物理验证仍必要。
