## 柔顺性的证据链

先说明是否完成任务和是否真正遇到干扰，再解释接触负载与恢复。固定沿用已有
`paper_metrics_20261002.py`定义：球、人手、推杆、未知桌边、柱子分别报告实际接触覆盖率、
接触期间P95力、峰值力、力模积分、接触时长。未接触不是“零力柔顺成功”：比较表显示NA；
物理日志中的零力记录保留原值。力模积分不是带方向的净冲量，两者不能混称。

每个指标同时展示全队列完成/失败和暴露情况；在双方都严格成功且都接触的配对上给出
条件性差值，注明这是结果条件化子集，不能替代全队列结论或证明普遍因果优势。短回合
的RMSE、力积分不混进完整55秒统计。若配对子集为空，保留NA，不删掉该方法。

恢复沿用25mm误差、25mm/s速度、连续0.5秒并有后续路径进展的settled-rejoin诊断。
同时报告恢复事件数、未恢复右删失数、观察窗口，不把删失值当成0秒或无限大均值。
快速完成可能不满足低速settled-rejoin，需结合放置/进度解释，不改成功gate。
推杆保持期间无接触间隙仅在确实发生过接触后报告；它本身不证明末端蹭开或成功放置。

RMSE、累计误差、实际执行器峰值力矩、力矩变化率、实际末端峰速、机械功作为补充。
更大峰速不自动意味着更好柔顺性。性能主张需要成功、负载、恢复与安全证据共同支持。
现有场景是固定几何下的小范围扰动分布，不称跨环境、真实办公室或真机验证。
