## 驱动、时序与残留对象

world_step中的人和杆均使用`clip(kp*(target-q)-kd*dq+bias, -limit, limit)`的广义驱动力。
人基座kp1000/kd180、限幅80 N；肩/肘另有90/15/20 Nm和65/10/12 Nm的驱动。
杆kp160/kd12、限幅14 N。**这些是驱动力限制，不是机器人接触峰力上限**；惯性、弹性和接触求解可产生不同峰值。
手/杆均用平滑位移目标；人进/保持/退为2/3/2秒，杆为1.5/6/2秒。
登记条件要求杆起推晚于人收回至少1秒；实际接触还由机器人轨迹决定，不能只用事件计划判断暴露或恢复。

MJB实际有3个旧mocap body，不能写“整个模型没有mocap”：
moving_obstacle在公开1375帧中一直位于(3,3,3)m，碰撞mask仍存在；另外两个透明marker留在(0,0,1)m且不碰撞。
相关环境源码的本轮路径每物理步将旧moving_obstacle放在(3,3,3)m；实际球、人、杆、物块均不是mocap。
模型共有9个actuator（7电机、夹爪、旧rod_driver），本轮office推杆使用独立qfrc_applied，不把旧驱动±300 N当作当前推杆设置。
唯一equality是两手指同步，模型没有weld。旧对象保留原样，本次不做可能破坏公平性的模型清理。

## 这能支持什么

可报告固定仿真装置中，在相同扰动身份/规划/WBC/执行器约束下的任务、穿透、接触负载与恢复差异。
抓取是物理接触支持；同时物体、摩擦、人体代理、传感器与接触求解仍属特定仿真假设。
因此目前不支持真实人体安全、任意办公环境泛化或硬件可部署的结论。

前次短步长检查已发现球峰力50→25 μs变化10.4%，力模积分变化约.5%；该单次积分相近不证明全场景收敛。
首撞时钟审计也表明首段峰值发生在25 Hz actor获得碰后反馈之前。
论文的柔顺结论应结合碰后持续接触、恢复、是否实际暴露与任务完成，不能凭球撞峰值或低速度单项宣称ESN最好。
本次不新增指标、不改排序、不放宽.2 mm门槛，也没有替代最终38模型×24条件评估。
