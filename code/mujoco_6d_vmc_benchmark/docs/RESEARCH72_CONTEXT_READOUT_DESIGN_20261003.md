## 结构与约束

保留128个固定储备池单元、原输入变换与多时间尺度。令r为更新后的储备池状态，c为已有
12维本体context（指令/测量相对运动、路径方向和参考相对位置误差）。增加128个固定交互特征：

`z = r * tanh(G @ c)`，`G.shape = (128,12)`。

G由训练seed+50000初始化，元素标准差1/sqrt(12)，始终固定，不接受梯度更新。
z接在已有特征之后、禁止直接产生动作的context字段之前。只训练最终线性系数，
输出仍用原有clipped-linear与共同执行器filter。此读出对扩展特征是线性的，
**不再是单独对r与c的线性和**，因此必须披露固定非线性交互计算。

这是储备池读出扩展，无运行时teacher或经典控制器混合。仍128个储备池单元，
但增加128个固定交互特征与1536个固定投影系数，不能称总参数/FLOP完全相同。
ESN训练系数由2884变3780；同特征MLP/RNN分别23748/40132。原网络完整保留。

新特征使相同记忆在当前负载归零后仍能随本体context改变动作。r=0、负载=0时，
所有新交互也为0；直接context读出仍严格禁止，所以任意context不能凭空生成零状态动作。
标准tanh储备池、0<leak<=1、零初态保持每个状态有界；固定tanh投影与最终限幅保持输出有界。
这仅是状态/动作有界性质，不是机器人闭环稳定、接触安全或无源性证明。
