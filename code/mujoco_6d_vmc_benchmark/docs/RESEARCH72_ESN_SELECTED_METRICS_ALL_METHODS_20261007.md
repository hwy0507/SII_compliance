# ESN 重点指标的全方法统一统计（2026-10-07）

本表覆盖用户指定的全部 16 个方法，全部来自同一 office-v6 frozen 环境、同一 24 个 held-out 条件和统一单模型 cohort。没有新增仿真；数值由最终逐回合报告和柔顺性统计重算。

## 选取的指标

为了体现 ESN 的主要行为，同时避免只展示有利数字，主列固定为：

- `Task`、`Strict`：任务和物理有效性主结果；
- `RMSE`、峰值速度：执行质量；
- 人手/棍子接触力 P95：接触柔顺性；
- 人手/棍子恢复率、最大穿透：恢复能力和安全约束，作为 guardrail 一并报告。

接触指标只在事件确实暴露的回合计算；恢复率没有把右删失回合当成失败以外的零时间；最大穿透取外部与未知边缘穿透的较大值。

## 如何解读 ESN 的优势

在学习控制器之间，ESN 的 Task、Strict、RMSE、峰值速度和人手接触 P95 都优于 matched RNN/MLP；棍子接触 P95 也略低于 matched RNN。Enhanced teacher 的 Task 为 24/24，但其 Strict、RMSE、人手接触 P95 和恢复率并不全面领先。

低速度或低 RMSE 的 RL/zero 行不能单独解释为柔顺，因为它们的 Task 为 0/24。Classic VMC 的棍子恢复率为 24/24，但任务成功为 0/24，因此恢复指标必须与任务完成和穿透约束同时报告。
