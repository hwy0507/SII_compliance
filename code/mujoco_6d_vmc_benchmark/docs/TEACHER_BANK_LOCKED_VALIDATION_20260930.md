  对保存元数据和hash做绑定，未独立重建每个子步的接触距离。不能调高门槛追认成功。

  连续接触，仍未满足1cm接触内切向移动及撤回前0.2s脱离。三者都没有完整录取。
  没有做无推对照，不能把观察到的运动方向/阶段停滞解释成唯一因果机制。
