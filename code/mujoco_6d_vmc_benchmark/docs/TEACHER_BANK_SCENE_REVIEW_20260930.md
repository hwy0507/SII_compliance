## 优先修复项

### P1：闲置球与棍子停车位重叠

`training_xml` 在 passive_corner 和 active_long/person 条件中，同时将球与棍子放在 `(1.7, -1.5, .3)`。
球与 capsule 属于不同刚体且碰撞位有效，存在初始实体重叠。
`office_task_v4.audit_initial` 对不同 body 的穿透阈值是 **10 μm**，应直接拒绝这些条件；不能放宽该检查。

修复：为闲置器械使用分离停车位，保持真实碰撞属性。不要用禁用碰撞、绕过初态审计来隐藏问题。
增加无需积分的 MJCF/初态检查后，再按单仿真资源约束执行动态 pilot。

### P1：被动类 contact 筛选可能把正常放置当成厚桌角碰撞

当前 `robot_contact` 累加所有 `office_v5_corner*`，包括最终支撑 top，且不限制任务阶段。
`corner_target_by_stage` 也把 top/face/bridge 混合。即使厚桌角 face 没被碰到，普通放置/支撑也可能满足 contact 条件。

修复：训练专属诊断按具体 geom、阶段、时刻与手/物块速度分别记录。要求目标边缘在上抬阶段出现真实力承载接触，
保留碰撞前正向上抬、接触期间滑移、脱离与后续任务成功证据。最终 top 支撑必须独立记录，不能替代障碍接触。
阈值应在批量运行前预注册，不能看过候选成绩后放宽。冻结综合 test 不变。

### P1：长期主动类尚不能证明“棍未撤回时自己蹭开”

沿用 evaluator 的 `duration_s > .4` 只证明累计接触；`rod_longest_run` 的 XY 位移也未区分法向让位与切向滑移。
当前审计未使用该诊断，未要求脱离发生在撤杆之前，也可能通过若干短接触累计满足 .4 s。

修复：在训练专属诊断中记录实际接触区间、器械实际位置/速度、驱动参考、手部位移沿推力轴及其正交方向的投影。
对于棍子，单独判断“已经连续受推，然后机械臂切向运动，并在器械开始回撤之前脱离”；设稳定脱离窗口避免单子步间隙。
人手条件记录持续受推与让位恢复，不强行把棍子的滑开判据套到手推。诊断真值仅用于采样/审计，不进入 actor。

### P2：训练中的厚桌角 face 目前没有与桌角 top 连成一体

沿用 combined-v4 的 face 中心为 `(.480,-.150,.520)`，基准半尺寸 `(.012,.010,.020)`；
top 的 x 范围为 `[.570,.730]`。即使计入当前 face 位移、旋转与厚度变化，其与 top 仍有明显空隙。
这是静态悬空局部障碍，不能直接称为整体厚 L 桌角。

可选修复：仅在独立训练 XML 中构建几何连续的连接段并审计可达性/初态，或明确登记为“局部边缘等效碰撞体”，
另外保留真实厚桌角子集。不能修改冻结综合场景以回避既有 baseline 对齐要求。

## 球/短期碰撞检查

- 当前发射公式 `launch = nominal(start+flight) - axis*speed*flight + (0,0,g*flight²/2)`，配合水平初速，
  在自由飞行且忽略接触时能到达离线目标，方向符号合理；scene 元数据未进入 actor。
- 离线 reference 来自一个已有 corner teacher 轨迹；各候选参数会改变进度与手部位置，因此同一 fixture 实际可能未击中。
  必须保留未击中结果，并将“接触未曝光”和“已接触但控制失败”分开统计，不能把 1000 个配置称为 1000 条合格示范。
- 现有 delayed launch 在发射前每个子步固定球 pose/qvel，是一种发射装置初始化假设；发射后才自由运动。
  文档应明确此事实，不能声称全程无外部保持。延迟 hold 期间的任何碰撞也需检测，避免隐藏的接触约束注能。
- sphere/ellipsoid/capsule 改变质量/惯量、接触法向和反弹方向。发射轴速度反号是可保留的严格反弹条件，
  但不是所有非球形合理散射的必要条件。分开报告“实际接触”“离开机器人”“轴向反弹”，不要调门槛把失败改成成功。
- 当前角度只有水平 yaw `[-.6,.6]`，时刻 `[2,12]`；应准确报告覆盖范围，不能称覆盖所有方向/任务阶段。
  静态几何检查与少量代表 pilot 通过后，才决定是否在另一个版本拓展俯仰/飞行时间/形状朝向。

## 采样与 baseline 公平性

- 设计定义每类 1000 train、100 validation，分割在优化前完成，符合训练/验证隔离的方向。
  生成数量、物理可执行数量、接触曝光数量、任务成功数量、最终合格轨迹数量必须分别计数。
- `physical_config_sha256` 目前也包含对本类别不起作用的字段，不能单独用它证明实际模型物理多样性。
  每个编译后的模型 hash、实际启用参数与时序一起用于确认唯一性。
- 力度参数应区分球动量/动能、器械驱动力上限与实际接触峰值/冲量。推杆最大驱动力不是实际施加到机器人上的恒定力。
- VMC、导纳、阻抗应使用相同 fixture-id/seed、相同有效曝光与安全判据、相同调参预算定义。
  可以分别优化参数，但不得为某一方法重采样更容易的环境，或把只由 VMC 成功筛选后的场景作为最终公平测试。
- 当前 score 中的 `retreat` 阶段进入时间只是完成效率 proxy，不等于放置稳定、开爪、退回均已完成的时刻。
  报告保留 proxy 名称，后续用独立满足 task completion 条件的时间补充。

## 后续实现：训练专属只读曝光审计

已新增 `tools/teacher_bank_exposure_20260930.py`，由主 agent 接入独立训练 adapter；
本实现不修改冻结综合 evaluator 的磁盘源码，不向 actor 写入任何真值。

- `TrainingExposure(fixture)(m,d,env,task)` 每物理子步读取接触与状态，保存 4 ms 展示聚合，
  同时保留由子步形成的稀疏连续接触区间。短于 4 ms 的接触间隙不会被降采样掩盖。
- 被动类只计 `office_v5_corner_face` / `office_v5_corner_training_bridge` 与机器人或 payload
  在 lift/carry 的承载接触；同一接触段超过 0.2 ms，净向上位移至少 0.1 mm，排除最终 top 支撑。
- 棍推要求同一连续接触段超过 0.4 s，接触中净切向位移至少 1 cm，并在撤回开始之前连续脱离至少 0.2 s。
  人手要求同段持续受推与至少 1 cm 净让位，不要求撤回前脱离。
- 球记录真实接触与发射前碰撞；反弹、任务成功、安全仍必须与原 evaluator 的独立判据联合，
  `summary().passed` 单独不意味着合格 teacher。
- `save(folder)` 写 `exposure.npz`；`audit_saved(path,fixture)` 可不加载 MuJoCo，独立重算曝光判据。
  审计检查聚合时间连续、总时长、terminal、contact interval、NaN、run 与 4 ms 接触时长一致性。
- callback 的 `d.time` 为已积分后的时间，记录区间使用 `[d.time-dt,d.time)`。
  当前 live `d.xpos` 与接触力均是动力学调用保留的状态；不冒称它们与重新计算的 post-step kinematics 完全同步。

验证：`tests/test_teacher_bank_exposure_20260930.py` 的 20 个纯数组测试通过，涵盖接触后滑开、
只法向让位、回撤后才脱离、静止/最终放置假阳性、亚毫秒间隙、发射前接触和损坏数组拒绝。
这些测试没有创建 MuJoCo 仿真环境。真实曝光/任务通过仍待主 agent 的动态 pilot。
