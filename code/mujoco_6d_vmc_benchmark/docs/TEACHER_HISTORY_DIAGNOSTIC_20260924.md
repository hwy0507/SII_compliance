## 基于证据的最小修正

最小修正应先改数据进入训练的资格检查，暂不改ESN结构或添加低通：将本批明确保留为失败诊断集，不自动加入原成功教师bank，不用其结果重选原模型。未来teacher补集必须先同时通过原task和strict gate，并记录真实接触阶段、释放/恢复；0/12说明当前固定教师方案尚未取得合格的新示范。

下一次有限实验应先做teacher可用性对照：在预声明的新train开发条件上，用同一完整runner检验确定性选定的原教师配置与一个事先固定的候选控制器，先证明真实任务与接触恢复可完成；只允许train开发选择，保留失败且冻结后才评估独立validation。当前960x/961x已用于本轮诊断，不能再声称为未见盲测；930x/940x评估轨迹仍不进入训练。没有合格teacher前，不启动大规模重标注或DAgger。

若后续取得合格补集，MLP/ESN必须同时使用相同新增train轨迹与预算，并报告平移/旋转分量及安全slew误差、闭环task/strict、子步物理峰值、追踪与接触恢复，不能只优化一个总MSE或只改善ESN。以上为下一步建议，本轮未执行新仿真、采集或重训。
