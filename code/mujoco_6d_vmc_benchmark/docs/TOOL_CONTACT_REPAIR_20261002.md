## 已确认的效果

使用相同MJB和ESN，另跑3秒球初速度为零的对照；发球前手部轨迹逐元素一致。
2–2.7秒内，真实球撞导致额外末端位移峰值 **13.845mm**。球只接触掌部`hand_collision`，
冲量2.6329N·s、累计接触.0073秒；瞬时碰撞峰力约6523N，不是可以忽略的软球冲击。
这里验证可见物理响应，不声称该冲击强度已适合真实硬件。

棍只接触`hand_collision`，未与物块或人体发生力承载接触。13.1484秒开始推掌部，
累计接触1.5937秒。在保持期内，相对初次接触的末端最大沿推压方向位移19.386mm、
垂直于推杆轴的位移50.062mm；这些是实际位移，包含原任务运动，不能全部归因于柔顺算法。
逐物理子步审计确认 **15.1201–19.1801秒** 棍行程仍>225mm、每个子步掌部接触力均≤.05N：
确有“棍未撤回，末端已滑出受力接触”的窗口。之后会再次接触，最后接触23.4695秒；
最长严格连续受力段只有.1061秒。**不是平滑、一次性、永久脱离，仍有接触抖动和回碰。**

球/棍阶段前28秒机器人外部穿透最大.111485mm；棍—掌部最大.060899mm。
新增接触日志独立回跑28秒，与完整回合前28秒的qpos/qvel/action/储备池逐元素一致；
无诊断日志改变动力学的证据。球反事实和完整回合MJB均为
`b092662aa1d6fba12357cd0a6271d309abeb047ad09f20a0a646d48415b637a1`。
