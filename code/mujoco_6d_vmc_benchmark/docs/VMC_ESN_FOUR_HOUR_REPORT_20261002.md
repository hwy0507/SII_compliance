## 已确认的因果结果

1. 零动作名义控制在未知凸边卡住；原VMC同样没有越障完成放置。优化RMSE不能代替恢复能力。
2. 各向异性弹簧与单纯放大垂直读出容易先水平卸载，仅发生毫米级上抬。更强负载耦合能
   将物块明显抬起，但过冲后重新掉回凸边；必须同时处理抬升幅度、持续时间与恢复路线。
3. 原VMC及coupled teacher的纯ESN能大致复现这种失败轨迹。尚无成功teacher轨迹，
   同时后期学生又出现明显闭环分布偏移：仅拟合teacher历史不足以恢复其实际行为。
4. 相对名义参考的有界虚拟平衡点，是teacher专属主动恢复机制；不是纯被动VMC，也没有
   被动性证明。只能用既有估计负载、名义/实测运动和相对位置误差，不能读接触/障碍真值。
   所有学生闭环仍是纯ESN，不包含teacher、手写恢复逻辑或VMC混合。
5. 各项峰值由550000个物理子步统计。若干候选峰速发生在约2.06秒球撞；不能用
   后段卡住的小速度掩盖该峰值。峰矩使用真实`qfrc_actuator`，不是神经网络action大小。

## 数据与工程审计

本轮所有模型保持128储备池单元；学习读出另含128个非线性单元与线性跳连。因此准确名称
是多时间尺度储备池＋非线性读出纯ESN actor，不能称经典的“只训练线性读出ESN”，也不能
声称与历史MLP严格参数/FLOP匹配。本轮没有重新训练或评估MLP。

- 每条物理回合保留source overlay、配置、seed、checkpoint/hash、execution、原始轨迹、
  请求动作、公共filter结果、实际力矩/速度/误差；独立重放动作和储备池并复算三指标。
- 新增context仅由canonical既有字段派生。神经读出采用共享权重
  `tanh(load+context)-tanh(context)`，无直接context动作分支；无负载、零初态时对任意
  参考严格输出零。已有历史状态仍可产生因果延迟响应，这正是待验证的记忆功能。
- 实际teacher执行标签与明确标注的其他轨迹反事实重标注分开，失败teacher不称合格样本。
  原始物理轨迹不随机拆帧当留出。导出checkpoint逐步重放、未使用字段扰动隔离、
  零初态/任意参考检查均通过；回放误差不等于闭环成功。
- 首个诊断模型误用通用.16m/s标签尺度，在物理部署前拒绝；保留REJECTED和原产物。
  后续显式采用实际office .32m/s公共filter，并在训练前严格对齐实际执行链，未改环境。
- 第12条物理已完成，但JSON最后写入遇到NumPy数组而失败。保留原execution/log，
  独立RECOVERY_AUDIT确认源、原始轨迹和指标，再接续13–17；没有重复仿真或抹掉故障。
- 最早训练的源码快照缺口已按原metadata逐文件hash恢复；后续在开训时直接保存源码归档。
  每条execution中的base commit不是干净运行版本，run专属overlay与逐文件hash才是权威。
