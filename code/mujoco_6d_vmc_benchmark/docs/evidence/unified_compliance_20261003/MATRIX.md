## 解读边界

- 七个RL模型全部列入：三种在线参数控制及两种reward×两个seed的直接action控制；经典固定/本轮调参、teacher、全部MLP/RNN/ESN和无记忆对照均未遗漏。
- RL及七个经典baseline本组task均0/4，因此与ESN没有共同strict成功条件。可以报告上面的实际接触负担，但不能据此算“同等完成任务下ESN降低力百分比”。
- 低RMSE可能来自卡住或不让位，低力可能来自未碰到障碍。接触位置、持续时间、任务进度不同，本矩阵不是固有刚度/导纳的辨识。大量恢复被删失，恢复时间不足以全面排名。
- 球峰力为毫秒级刚性接触仿真瞬态，步长/接触求解器敏感；不是实际机器人碰撞力或人体安全结论。
- 训练曝光不等：ESN/MLP/RNN使用本轮office teacher数据，RL来自此前primitive训练的冻结迁移；同宽128也不等参数量。结论只针对这些checkpoint在当前世界的表现，不宣称算法族普遍优越。
- 已知正式步长dt=5e-5的两个ESN均放置失败；本矩阵不替代该结果。随机补充和formal只测开发合格子集，不能并入完整26方法的分母。
