# 最终结论 — 延迟线索实验（v12/v13）与整体交付

**日期**: 2026-08-21

## 延迟线索实验：诚实的否定结果

**设计**: t≈1.1s 一个短暂可观测微扰（腕部力矩脉冲）预示 t≈3.15s 的猛击；
WBC 在 ~0.5s 内抹平瞬时痕迹 → 到撞击时只有"积分过线索"的控制器（蓄水池）
才能预判。含假阳性板（有线索无撞击，正确行为=什么都不做）。

**结果**:
- 弱线索（8Nm）: 学生学不会桥接——cue 板上 ESN 峰值 ≈ FW ≈ MLP（179/166/188N）。
  慢蓄水池变体（tc 0.3-0.5, sr 0.95-1.1）也桥接不了 1.9s；tc0.3 仅有微弱迹象
  （155N vs FW 166N）
- 强线索（16Nm）: 任务本身被摧毁——微扰落在下探/抓取阶段，FW 教师 MLP 全线
  丢块（教师峰值 800-1250N，all-ok=0）
- **结论**: 该观测集下的 ~2s 线索桥接需要专门架构工作（显式延迟线特征、
  线索预训练等），不是场景设计能解决的。如实记录为 future work。

### 表 2 — 175 次独立重训统计（权重免疫的证据）

ESN vs MLP 头对头 **4/6 指标占优**: 力积分(92.2 vs 97.3)、峰值(119.0 vs 128.5)、
回位(0.7 vs 3.8mm)、接触柔和度(MLP 抖振最差)；MLP 仅在接触时长/饱和秒数占优。
综合分 53-56% 胜率=统计平手；**权重敏感性分析（2000 组随机权重）表明任何单一
综合分排名都依赖权重选择**——因此论文主张应落在逐指标优势 + 权重敏感性披露，
而非单一分数排名。
