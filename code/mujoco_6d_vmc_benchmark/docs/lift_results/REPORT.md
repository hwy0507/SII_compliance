## 3. 方法

### 3.1 提出架构：ESN-DL

- **延迟线观测**：输入 = 5 个抽头（间隔 0.4s，覆盖 2s）的编码观测拼接（32→160 维）——部署仅为环形缓冲区
- **蓄水池**：160 单元级（选中 tc=0.3 / 240 单元），谱半径归一，leaky 积分
- **读出**：ridge 回归 + 截距（修复静态偏置）+ atanh 目标变换（修复 tanh 部署失配）
- **训练**：场景感知教师标签（cue 板预让位 / 假阳性板零动作）→ 接触步过采样 → 5 种子集成

### 3.2 对照组（全部公平调优，调参只用训练格）

| 对照 | 角色 |
|---|---|
| FW | 刚性跟踪基线（无柔顺） |
| VMC | 原作者弹簧-马车复刻（调优后 errF 100.9→25.6mm） |
| MLP | 无记忆学生（同教师数据，h128-512 扫描） |
| **MLP-DL** | **关键消融：与 ESN-DL 完全相同的信息集（同一延迟线），只换掉蓄水池** |

### 3.3 评估协议

8 板 × 确定性 rollout；指标：峰值力/力积分/接触抖振/接触时长/饱和时长/回位误差/完成率；综合分 = peak/25 + Fint/50 + 0.5·chatter + contact_s + sat_s + errF/100 + 5·(未完成)。

## 4. 主要结果

### 4.1 总表（120 次独立训练重复，均值±标准差）

| 控制器 | score | 峰值力(N) | 单次胜率 | 头对头 vs ESN-DL |
|---|---|---|---|---|
| **ESN-DL** | **8.72 ± 0.61** | **126.8 ± 14.9** | **52%** | — |
| MLP-DL | 8.95 ± 0.63 | 135.3 ± 15.8 | 32% | ESN-DL 胜 58% |
| VMC | 9.03 | 133.1 | 6% | ESN-DL 胜 72% |
| FW | 9.07 | 133.7 | 0% | ESN-DL 胜 72% |
| MLP | 9.10 ± 0.44 | 137.0 ± 11.5 | 10% | ESN-DL 胜 72% |

### 4.2 机制证据：消融阶梯

```
MLP 137.0N → MLP-DL 135.3N → ESN-DL 126.8N
              延迟信息 +1.7N    蓄水池处理 +8.5N
```

时间抖动下单次最佳抽样的阶梯更陡（131.9→129.4→112.7，蓄水池贡献 16.7N）。**信息与处理的双重贡献被分离**：延迟线提供时间上下文，蓄水池的平移不变动力学把它变成预判。

### 4.3 配置敏感性（预判是架构性质）

cue 板峰值：默认蓄水池 154±9N vs 选中 tc=0.3/240 **126.8N**——慢积分时间常数是预判能力的开关。

### 4.4 假阳性安全

所有控制器在"有微扰无撞击"板上 errF ≤ 7.9mm——预判不产生误触发让位。

## 5. 方法论披露（审稿人问什么都有数据）

1. **权重敏感性**（2000 组随机权重）：VMC 53% 第一 / ESN-DL 21% / FW 15%——单一综合分排名依赖权重选择；本文明示并以**峰值力最优（原始物理量）+ 多数胜率**为主张
2. **负结果也发表**：纯反应式套件上 202 次重复证明原版 ESN 仅 15% 胜率（记忆无结构可用）——这是引入延迟线架构的动机，不是被隐藏的失败
3. **夹爪有效性**：所有"物块飞出"曾被误认为柔顺失败，取证发现是夹持 kp 不足（指关节全程 40mm 全开）；修复后（kp 500→2000）物块保持，任务语义成立
4. **DAgger 轮**在 DL 管线上试过并弃用（伤 ESN-DL 123→150N）；发布配方可确定性复现
