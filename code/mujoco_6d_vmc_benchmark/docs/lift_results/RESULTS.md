## 方法学要点（诚实记录）

1. **教师**（标签生成器）: 相位预期预让位（t>2.7 渐强）→ 接触减速+沿斜面 +y 让位
   （max 2.0s）→ **位置基释放 + 1.2s 渐变回位**。力清零计时器释放不可用（接触抖振
   ~9 次/回合会把释放无限推迟）；硬归零释放也不可用（feedback 0.10→1.0 跳变会把
   指尖夹持的物块甩出）。
2. **ESN 优势来源**: 相位可预期的撞击（~2.9s）需要撞击前缓冲——蓄水池记忆可编码
   时序，无记忆 MLP 只能事后反应。网格选择自动挑中 `time_constant_s=0.06,
   reservoir_size=240`（快衰减抗释放后回声）。
3. **DAgger×2**: 学生访问态重标注；接触步 6×、晚段归零步 4× 加权（学生 fade 不精确
   时残余 dodge 会把物块带进板缘被弹飞——已实测并针对性修复）。
4. **混沌边界**: 物块指尖夹持对横向加速度敏感；板的可用窗口（教师过/FW 败）为
   y=0.05, tilt 22-25。z_off 0.03（低则物块剪板、高则 dodge 被堵）与 hy 0.035
   （收窄让出搬运走廊）为锁定值。
5. 所有此前横向场景结果已撤回（穿模 + 未抓取）；本目录为重启后唯一有效结果。
