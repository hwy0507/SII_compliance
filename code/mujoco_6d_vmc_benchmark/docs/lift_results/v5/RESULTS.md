## 训练要点（本轮关键修复）

- 教师 = "缓起半幅"预期（0.4s 只升至 50%，接触后全幅）：时序错也只错一半，
  学生相位推断不再脆（此前静态板 280-433N 尖峰 → 现在 116N）
- 教师选参改为全套件均值（只在载荷板上选参会饿死静态板的 dodge 深度）
- DAgger×2 + 接触步 6×/晚段归零 4× 加权
- 数据格：每类场景 2-4 个变体（静态 21/23/24/25°，板 t0/高度/速度扰动）

## 分场景观察

- **plank_payload**: 全员完成，力差主导（ESN 峰值最低）
