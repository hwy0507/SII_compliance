## VMC 选择协议

VMC 的第一阶段只在首个评估种子上做 sweep，之后固定选出的场景配置跑五个种子：

```text
rod:   k=2.2, budget=0.05
ball:  k=1.5, budget=0.03
board: k=1.5, budget=0.02
```

因此 `vmc_best/*` 是可用于多种子比较的结果；`vmc_k*` 是首种子的调参记录，不能当成独立评估样本。

## 方差解释与边界

每个格子在五个种子上的数值完全相同（浮点显示误差约为 `1e-15`）。这说明当前 Paper-MPC benchmark 的 fixture、参考轨迹和 MuJoCo 初始状态是确定性的；`seed` 目前主要用于协议溯源和未来引入扰动时的扩展，并不等价于“5 个独立随机物理实例”。因此本次结果可以报告为 5-seed 可复现性，但不能把零标准差解释成对随机动力学扰动的统计置信。

下一步若要获得真正的跨实例统计，应在不改变任务定义的前提下显式随机化并记录：初始关节微扰、冲击器初始位姿/速度、接触摩擦或质量；同时保持训练/评估隔离并在 manifest 中固定随机化范围。
