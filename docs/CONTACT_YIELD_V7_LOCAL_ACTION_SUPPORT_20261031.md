# v7 MLP 棍推局部动作支持诊断

## 结果

对锁定v7训练数据中所有正权重teacher标签，按原18个输入字段、train-only标准差（下限0.005）、`[-12, 12]`裁剪和绝对值扩展，精确计算固定27三条棍推MLP轨迹每一帧的10近邻。零权重学生warmup行未作为teacher监督参考；参考集共16,416帧。分析脚本与结果JSON逐项绑定数据、审计、模型锁、开发review及三条原轨迹哈希。

## 解释边界

在可见的首次碰撞前4.2–4.7秒，失败seed的最近训练状态距离、10近邻teacher动作离散度和学生动作差均没有高于通过seed01的同等量级。这不支持“首个碰撞前已明显脱离训练支持域”或“可见18字段对teacher动作高度多义”作为已证原因。4.7秒后，失败seed02/03的距离和动作差持续增大；seed01也有短暂状态偏移，但其5–8秒指标较低并随后回到训练支持附近。

关键时间顺序限制了解释：seed03在4.69900秒首次超过穿透门，seed02在4.78050秒首次超过。故4.7–5秒窗口包含首个越限事件或其后状态。大近邻距离和动作差与危险碰撞及其后分布漂移相符，不能证明它们导致了首个碰撞。邻近动作取自其他已观测teacher状态，不是teacher在学生当前状态上的反事实动作；近邻之间存在轨迹时间相关，10近邻离散度也不是校准的条件方差。

当前证据没有发现MLP加载、预处理或公共filter错位；本诊断也没有确定MLP首个安全余量损失的根因。适合继续追查的对象是逐actor-step对齐的首个穿透前关节位置/速度、请求动作、滤波后twist和slew/amplitude状态，并与通过seed及纯teacher对应时间对照。分析应停在保存轨迹层，不改物理、输入、filter或gate；若需新teacher监督数据，必须另做合格的真实teacher rollout，不能把近邻标签或失败后缀当作示范。
