# 原25条与扩展55条示范：新指标复核

## 结论

目前不能认定55条在新评估矩阵下整体优于25条。入选示范都是Task/Strict双通过，
55条的平均回合峰值力矩比25条低0.1605 Nm（0.32%），差异很小；原25条缺少可读取的
原始完成时间/接触子步记录，无法完成两份数据的统一SPT和舒适力矩比例比较。
这不是ESN/RNN/MLP训练效果比较，也不是新旧教师在相同条件上的配对实验。

本轮读取真实数据与历史审计；新增训练0、仿真0。55条包含原25条和新增30条。
两份NPZ全部10个字段的原34375帧前缀逐值一致；原20/5、新24/6的训练/验证划分不变。

## 口径、验证与缺失

- 使用`EVALUATION_STANDARD_SPT_20261025.md`及现有非RL矩阵函数。
  完成时刻按25Hz终态放置连续保持gate；物理步长5e-5。
- 舒适阈值`[43.5,43.5,43.5,43.5,6,6,6] Nm`，人体接触`human_robot_sum > 0.05 N`，
  以实际接触dt为分母，七关节同时合规，保留已登记1e-6相对容差。
  群组比例按接触时长加权。它是驱动力矩的经验代理，不是人体舒适认证。

  原子步文件与已登记hash，30条入选数据另核对dataset lineage。峰值与原AUDIT一致。

- 原25条NPZ与资格记录仍在；NPZ只有观测/动作等训练字段，没有逐子步实际力矩、人体接触或
