# 人机柔顺控制评估标准：SPT 主效率指标

自 2026-10-25 起，本项目的目标定义为：在人机交互过程中避免人受到撞击、避免机器受到危险载荷，同时尽快完成任务。后续实验和 agent 必须把本文件作为正式评估标准入口。

## 指标优先级

主结果按以下顺序报告：

1. **Task success rate**：任务完成比例。
2. **Strict success rate**：任务完成且没有任何预登记安全违规的比例。正式“成功”优先采用 Task AND Strict，而不是只报告 reward。
3. **SPT（Success-weighted Path Time）**：成功加权的完成时间效率。对每条回合使用预登记的参考最优完成时间 `T_ref` 和实际完成时间 `T`：

   `SPT = success × T_ref / max(T, T_ref)`。

   未完成任务的 SPT 为 0。用户后续明确要求本轮非 RL 重评的 `T_ref` 使用所有被测方法中
   Task AND Strict 成功回合的最短完成时间；这是本轮采用的后验、矩阵相关参考值，覆盖本文件
   初版的独立参考规划器要求。候选方法、条件和取最小值规则在运行前冻结，完整矩阵结束后统一
   计算，不能删去失败或选择性更换参与方法。本轮使用全矩阵一个参考值，不是逐条件参考值；
   没有合格成功时 `T_ref=NA`、所有 SPT 为 0。完成时刻为终态放置 gate 首次满足连续保持的
   采样时刻（25 Hz，时间分辨率 0.04 s），不是固定回合时长或 retreat 事件。
   后验参考不是最优时间的证明，不宜跨不同方法集合/条件集合直接比较 SPT。
   若实验确实比较路径长度，可另外报告 SPL，但不能把 SPL 写成 SPT。

4. **峰值广义力矩**：报告全关节最大值、逐关节峰值和 P95；同时报告执行器幅值、变化率或其他机器安全限制是否违规。
5. **舒适力矩合规比例**：只在实际人机接触或预登记的人机交互窗口内统计，计算低于预登记舒适阈值的时间/帧比例。无接触的静止阶段不能进入分母。必须同时报告接触时长、阈值、超阈值持续时间和超额积分。

   本轮按用户授权经验定义：每关节阈值为冻结执行器幅值的 50%，即
   `[43.5,43.5,43.5,43.5,6,6,6] Nm`；只统计 `human_robot_sum > 0.05 N` 的物理子步，
   按 dt 加权，七关节同时满足阈值才计合规。无实际接触为 NA。这是驱动力矩的工程代理，
   不是人体感知舒适阈值的实验标定或人身安全认证，不能取代接触力/冲量报告。

6. **机器安全违规率**：本轮记录外部或 edge 穿透超过 0.2 mm、力矩超过冻结上限、
   非有限物理遥测或 worker abort 的回合比例；失败回合计入分母。力矩变化率仅诊断，
   因为当前没有独立登记的 slew 阈值。冻结 Strict gate 保持，独立安全违规列另报。

## 安全审计

“机器不坏”和“人不被撞击”不能只由单个峰值力矩代表。每条回合还必须保留：

- 人体接触力峰值、接触冲量和接触时长（若 runner 提供）；
- 最大穿透、力矩超限、力矩变化率超限、数值异常和提前中止；
- Task/Strict 的逐回合结果，失败回合必须计入分母；
- source、model、config、checkpoint、actor/filter replay 的 hash。

若没有实际人接触，舒适力矩合规比例应标记为 `NA`，不能用无接触低力矩制造高舒适分数。低力矩但任务失败的策略不能称为柔顺控制成功。

## 报告规则

不把多个指标未经预登记地压成单一加权分数。先给出 success rate、Strict success rate、SPT、力矩和接触安全的完整表格，再按预先登记的优先级比较方法。训练 reward 和 actor/critic loss 只作为训练诊断，不是最终方法优劣指标。

本标准改变的是评估指标和报告优先级；physics/MJB、最终 gate、canonical48 actor 输入、公共 action filter、执行器限制和 `dt=5e-5` 继续按仓库既有冻结约定执行。
