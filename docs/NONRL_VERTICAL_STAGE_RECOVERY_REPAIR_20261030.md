# 三特化主矩阵修复：竖直阶段横向恢复

本报告区分教师问题、学习问题和场景范围问题。尚未完成正式未见108评测，不能将开发验证写作最终成功。

## 已核实的三个问题

1. 原综合office108同时包含多种干扰，而新示范来自三个隔离特化场景；这批历史迁移压力结果保留，但不能作为新特化主矩阵。后继12个隔离未见条件已冻结，尚未曝光。
2. 原ESN的部分候选在闭环偏离训练特征范围后出现读出放大，ridge线性方程及动作导出审查未见计算错误。原完整12共同开发筛选后，三个ESN种子、三个RNN种子及一个MLP种子均各九条开发闭环合格；另两个MLP种子完整12耗尽仍无合格模型。不能说目前所有ESN都失败，也不能据开发资格宣称测试成功。
3. 原teacher在两条学生偏离轨迹上实际接管后未能回位，说明仅靠模仿更长训练不能保证修复。v1新横向反馈三个名义场景合格，两条175/275步安全学生前缀纠偏均Task和安全通过、棍推行为失败；越棍后最小管道距离约9.044/10.164mm。旧teacher的成功示范并未证明它会纠正学生到达的偏离状态。

## 纠正方向诊断

实际保存观测obs[45:48]在上述越棍后窗口为[0,0,1]，而非全零方向。`PrimitiveTask.direction()`在阶段位移很小时也约定返回竖直方向。只能解释为竖直方向编码，不能从该输入单独推断具体任务阶段或暂停。

v1只取水平投影obs[45:47]，为零时关闭反馈；v2保留历史水平向量，但遇非零竖直方向又清除，故仍没有解决实际恢复窗口。此前“整个方向为零／暂停”的判断错误；旧诊断的all_full_direction_zero断言实际失败且没有输出。新只读诊断逐帧重放原actor并核实际后缀action，明确上述事实，见`CROSS_TRACK_VERTICAL_DIRECTION_DIAGNOSIS_20261030.json`。

v2实际执行棍推和球撞两条合格后，桌角325步完整运行的收据因源码一致性失败而被拒：诊断脚本在该worker采集源码hash后修改。campaign起始登记源未变，但per-episode inventory包含后加诊断。故source_stable=false；该回合禁止训练标签，完整失败保存，后两条纠偏未派发。此为agent操作引入的来源失败，不得伪装科学失败或成功，不重启原v2。

## v3固定教师修复

版本`bounded_cross_track_recovery_v3`仅使用已有canonical48参考误差、当前路径方向与估计wrench：

- 非零水平路径沿用原水平横向投影；仅竖直路径时，XY两轴均为横向，采用水平单位投影；整个路径为零仍关闭新增反馈。
- 水平恢复速度为1.5/s乘投影参考误差，欧氏模限0.02m/s，再乘1/(1+投影力平方/1N²)载荷抑制。
- 将该速度除以公共0.32m/s动作尺度，作为teacher-only requested residual附加到原动作；继续走原公共filter与执行器限制。
- 不添加阶段、时间、几何、成功flag或未来方向输入；不改物理、MJB、gate、canonical48、公共filter或dt=5e-5。没有主张主动反馈的被动性或全局稳定性保证。

同一固定参数、同一五条训练身份：rod00/ball00/corner00纯teacher，再两条rod00的175/275步安全学生前缀。前缀沿用原MLP02 rank2，既有安全通过但回位失败；不按最终test调整。完整/异常worker胶合与loss mask、三种接管边界、实际两条[0,0,1]历史的恢复非零/有界/误差同向、真实prepare/check与重复拒绝已通过。它们属于零物理控制，不是修复成功。

## 结果与下一步

当前五回合有限真实验证见`outputs/vertical_aware_cross_track_development_20261030_v3/execution.json`；各回合完整结束后单独审查Task、棍推顺序、全部物理子步、动作/filter回放、穿透/峰矩/资源与来源。任何失败都保留。新脚本被登记后禁止再编辑，新增脚本也须先完成再开启下一campaign，避免再次触发每回合全源校验。

仅全部审查后才决定共享数据修复方案：实际teacher执行后缀才可能做label；学生前缀只提供完整历史warmup、importance=0，不能把反事实teacher输出当成功执行。共享同一数据/完整轨迹划分/三种子/每族每seed12候选和同一验证规则，公平重训全部三方法，不能仅给ESN加teacher或只挑成功seed。最终条件不参与修复。人体真实舒适通道仍缺，NA与接触力矩代理必须分列。

既有v1五回合（含两科学失败）、v2两合格及桌角来源失败完整raw归档另见`CROSS_TRACK_COMPLETE_SHARED_RECEIPT_20261030.json`；服务器仅存储/hash。旧综合矩阵和未完成57格均保留。

共享数据后继审查还须覆盖：验证MSE只能统计合格teacher执行label（不可含前缀反事实）；warmup行应推进recurrent state但不计监督loss，若整个TBPTT窗口权重为零，不应消耗有效优化更新或施加一次仅weight decay的更新；ESN也应推进同一历史并以零权重排除前缀正规方程。旧训练器未经这类mixed-history端到端控制，不可直接套用后声称完成公平增强。
